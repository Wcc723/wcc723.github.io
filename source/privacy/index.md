這頁說明你瀏覽 [www.casper.tw](/)（以下稱「本站」）時，有哪些資料會被收集、由誰收集、拿來做什麼，以及你可以怎麼關掉。本站由我（卡斯伯）個人經營，內容是前端技術文章，之後也會放一些免費的線上小工具。

## 這頁涵蓋的範圍

- 這頁只說明本站，包括文章、列表頁，以及之後放在本站的線上工具。
- 我經營的其他服務各有自己的隱私權說明，例如 [privacy.casper.tw](https://privacy.casper.tw/) 收錄的是其他軟體服務的政策，跟本站是不同的網站，以各自的說明為準。
- 本站網址底下另外有一些直接從 GitHub repo 發布的課程範例與專案頁（網址的第一段是 repo 名稱），它們不使用本站的版面，這頁提到的廣告與統計設定不一定適用，以各頁內容為準。

## 我自己不收集個人資料

本站是靜態網站，沒有會員、登入或表單，我不會要求你提供姓名、電子郵件或電話，也沒有自己的資料庫存放訪客資料。下面列出的資料，都是由本站使用的第三方服務（Google、Meta、GitHub、Cloudflare）依照它們自己的政策收集與處理。我能看到的只有 Google Analytics 這類彙總後的統計報表，看不到可以直接認出你是誰的資料。

## 廣告與 Cookie（Google AdSense）

本站用 Google AdSense 顯示廣告，廣告的位置與內容由 Google 自動決定，不是我挑選的。

- 第三方廠商（包括 Google）會使用 Cookie，依照你先前造訪本站或其他網站的紀錄，向你放送廣告。
- Google 使用廣告 Cookie，讓 Google 和合作夥伴能依照你造訪本站或網路上其他網站的情形，向你放送廣告。
- 你可以到 Google 的[廣告設定](https://adssettings.google.com/)停用個人化廣告，也可以到 [www.aboutads.info](https://www.aboutads.info/) 停用第三方廠商用於個人化廣告的 Cookie。

除了 Google，經過 Google 認證的其他廣告聯播網也可能透過 AdSense 在本站放送廣告並使用自己的 Cookie，同樣可以用上面第三點的方法，或到各廣告商的網站停用。停用個人化廣告之後，你仍然會看到廣告，只是內容不再依照你的瀏覽紀錄挑選。Google 怎麼使用這些資料，可以參考 Google 的[廣告相關說明](https://policies.google.com/technologies/ads)和[合作網站資料使用方式](https://policies.google.com/technologies/partner-sites)。

隱私權政策、聯絡頁、使用條款和找不到頁面（404）不載入廣告。

## 流量統計（Google Analytics）

本站使用 Google Analytics 4 統計流量，例如每一頁的瀏覽次數、訪客從哪個網站連進來、使用的裝置與瀏覽器，以及大概所在的國家或城市。Google Analytics 會在你的瀏覽器設定 Cookie（名稱以 `_ga` 開頭），用來區分不同的造訪。

- 我只看彙總後的報表，用來了解哪些文章對讀者有幫助、接下來該補寫什麼。
- 工具頁送出的統計事件不會包含你在工具裡輸入的內容，例如抽獎名單；音效庫的搜尋字詞例外，會記進 Google Analytics。
- 事件層級的資料會依照 Google Analytics 的資料保留設定，到期後自動刪除。
- 不想被統計，可以安裝 Google 提供的 [Google Analytics 停用瀏覽器外掛程式](https://tools.google.com/dlpage/gaoptout)，或在瀏覽器裡封鎖 Cookie。

## Facebook（Meta 像素與留言外掛）

- **Meta 像素（Facebook Pixel）**：每一頁都會載入。它會把你瀏覽的頁面網址、瀏覽器資訊和 IP 位址傳給 Meta；如果你同時登入 Facebook，Meta 可能把這些紀錄跟你的帳號連結，用在 Facebook 與 Instagram 上的廣告成效衡量與廣告投放。我用它了解從 Facebook 來的讀者，以及在 Facebook 推廣文章的成效。
- **Facebook 留言外掛**：文章頁和關於頁底下的留言框由 Facebook 提供。頁面載入時，你的瀏覽器會連到 Facebook 的伺服器，Facebook 可能因此收到你的 IP 位址與瀏覽器資訊，如果你已登入，也會知道你看了哪一頁。你留下的留言會用你的 Facebook 帳號公開顯示，由 Facebook 保存，要修改或刪除，請直接在留言框或 Facebook 上操作。
- 想調整 Meta 用來投放廣告的資料，可以到 Facebook 的帳號管理中心調整「廣告偏好設定」，或管理「你在 Meta 技術以外的動態」，中斷這類瀏覽紀錄跟你帳號的連結。詳細內容請看 [Meta 隱私政策](https://www.facebook.com/privacy/policy/)。

## 網站主機與連線（GitHub Pages、Cloudflare）

- 本站的檔案放在 GitHub Pages。GitHub 會為了安全目的記錄造訪者的 IP 位址，不論你有沒有登入 GitHub。詳細內容請看 [GitHub 一般隱私聲明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。
- 本站的連線經過 Cloudflare，用來加速、快取與阻擋惡意流量。Cloudflare 會處理 IP 位址、瀏覽器資訊這類連線資料；偵測到可疑流量時，可能設定安全用途的 Cookie（例如 `__cf_bm`、`cf_clearance`），這些 Cookie 不是用來追蹤你在不同網站之間的瀏覽。詳細內容請看 [Cloudflare 隱私權政策](https://www.cloudflare.com/privacypolicy/)。

## 文章裡嵌入的外部內容

部分文章嵌入了其他網站的內容，例如 YouTube 影片、SlideShare 簡報、CodePen 和 JSBin 的程式範例，也有不少圖片放在 Google 的 Firebase Storage。載入這些內容時，你的瀏覽器會直接連到對方的伺服器，對方可能收到你的 IP 位址與瀏覽器資訊，也可能設定自己的 Cookie，處理方式依照各網站自己的隱私權政策。

## 你可以怎麼做

- 在瀏覽器設定裡封鎖或刪除 Cookie，或使用無痕視窗。封鎖之後文章一樣可以正常閱讀，只是 Facebook 留言這類外部功能可能顯示不出來。
- 用上面各段提到的設定，停用個人化廣告、Google Analytics 或 Meta 的廣告追蹤。
- 對這份政策有疑問，可以透過[聯絡頁](/contact/)列出的管道找我。

## 如果你主動聯絡我

透過 Facebook 粉絲專頁或 GitHub 聯絡我時，我會看到你在該平台公開的名稱，以及你傳來的內容。這些資料只用來回覆你、處理你回報的問題，不會轉給其他人，也不會拿來寄送行銷訊息。對話內容存放在 Facebook 或 GitHub 上，依照各平台的政策保存。
